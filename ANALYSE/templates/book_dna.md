# Book DNA

## Evidence scope

- Book ID
- Covered chapters
- Source and Schema versions
- Known gaps

## Reading drivers

记录持续推动阅读的机制，并引用 arc 或专题报告。

## Narrative loops

记录循环步骤、触发条件、平均长度、阶段变化和失效条件。

## Payoff and reward system

分别记录冲突兑现、情绪爽点、物质或地位奖励、下一机会和下一冲突。

## Character behavior rules

使用条件与行为描述关键人物，避免只写性格标签。

## Pacing model

按开篇、中期和后期分别记录章数、字数和场景间隔。

## Hooks and information control

记录钩子分布、结果延迟和读者与角色之间的信息差。

## Foreshadowing model

记录短、中、长线索的跨度、强化次数、回收方式和未回收项。

## Craft hypotheses

每项包含判断、证据、替代解释和置信度。

## Transfer boundary

列出可以迁移的机制，以及必须删除的专名、设定和独特事件序列。
