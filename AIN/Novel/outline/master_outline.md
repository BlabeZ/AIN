# 总纲

- **暂定书名**：《别查了，你们找的幕后人物全是我》
- **一句话**：一个藏在口袋空间里的失落高维研究院，让分身觉醒者在万法并存的超凡社会里，把整张棋盘变成自己的多开游戏。
- **贯穿全书的一句话（ref04）**：关明衡从一个试图隐藏自己的觉醒者，逐渐变成**制造身份、制造组织、制造局势**的人。
- **内在驱动（ref05）**：他不能接受自己的命、以及自己在乎之人的命，被掌握在一个自己看不见的系统手里——"我要知道发生了什么；我要留后手；我要有选择"。
- **类型**：都市异能 / 幕后流 / 分身流 / 万法并存

> **管辖权**：总纲只管"核心卖点、篇章总览、最终方向、写作原则"。分卷的起承转合见 volume_NN.md，单章节拍见 outline/chapters/NNN.md（ref03-3）。

## 核心卖点
1. 分身流多身份潜伏：本体在官方，分身游走势力之间，情报碾压、自己查自己。
2. 幕后操盘：明面低调苟住，暗线越铺越大。
3. 万法并存：异能、修炼、魔法、神术、蛊术、机械、科学神教同台——统一在"超凡者"总称下（觉醒型/修习型/改造型/复合型，见 power_system.md）；**共同主题**：超凡力量究竟属于"人"、"传承"，还是可以成为"技术与资产"（异能者卖天赋/传统卖传承/机械卖工业能力；阿尔登"异能资产化"=把个人天赋变成工业产品，与主角"人的扩展"互为镜像）。
4. 金手指成长：研究院修复线 = 主角进化线 = 后期地图开启线（模块恢复制，不设总百分比）。**第一金手指永远是分身本身——研究院是把分身从"我多了一个身体"一路推到"我可以拥有多个真实身份、多个力量体系、多个世界人生"的进化器和放大器（ref25），始终不是"研究院帮关明衡把敌人处理掉"。** 研究院强度边界：最多解决"技术问题"不解决"社会问题"；解决"能力边界"不解决"当前危机"；前 100 章能力兑现最多三次（详见 world.md）。

## 主线钩子（三层）
- 近：协调局立足，摸清阿尔登国际实验线索——阿尔登把"能力"从人身上剥离、变成可交易可复制的资产（主角复现能力的黑暗镜像）。它的合法生意、反派哲学与人体实验是同一条线：**既然能力可以估值，为什么不能脱离拥有者交易**（三大核心竞争力=人/数据/定价，见 factions.md）。
- 中：商社做大，身份网横跨势力与星球。
- 远：研究院身世（四层答案回收，不进入故土）；方舟环大灾变预兆。多元宇宙文明=**世界观远景**，只作身世背景与宇宙尺度参照，不承诺进入（ref15）。

## 前期双核心主线（ref29 · 明线与爽点线互相驱动）
- **明线**：周磊到底发生了什么？
- **爽点线**：关明衡发现一个身体/一个身份永远不够。
- 两条互相驱动：周磊每推进一步，都逼关明衡开发一种新分身玩法——高中生不能查→分身查；分身不够→第二分身；官方身份不能查→百面；百面不能买材料→买家；阿尔登盯上百面→百面卧底；官方开始查百面→自己查自己。**爽点因果链 = 前几十章的主干。**

## 番茄平台适配（ref30 · 分级原则）
**适配分级**：剧情/大纲 ★★★★★（核心玩法提前、减少无效过渡；从"设定展开型"改"连续兑现型"）｜文风/人物 ★★★☆☆（压缩解释与氛围重复；强化首登场辨识度与关系冲突）｜世界观 ★★☆☆☆（内容少删，改变投放方式）｜副本/任务 ★★★★☆（每次任务必须产生永久收益或局势变化）。
**前台/后台分离（最重要的写作纪律）**：后台越来越复杂（作者知道 100：18 级体系/国际政治/航线/研究院模块/分身硬规则/Persona/道德原则），**前台越来越简单（正文现在只给读者 7）**——这一章关明衡想干什么？谁在阻止他？他准备怎么利用分身解决？解决以后出了什么新问题？**作者知道 100，正文只给 7，不给 70。**
**名词同屏密度**：读者一次只需记眼前有用的两三个东西——前十章只需"分身/研究院/协调局"；阿尔登先不告诉全貌；天幕/评级/同业会/山门/月球/平行宇宙/航线存在于 Bible，等剧情需要再上场。
**设定延迟释放（设定被迫因为一个问题出现）**：不在设定应该发挥作用之前解释它。例：初评只说"初评一级"，读者问"一级很弱？"答"评级不是境界，只是表示我们现在认为你大概有多难处理"——之后遇 6 级/10 级/高阶外驻再逐渐扩展。
**副本判断标准**：把关明衡的能力换成火系异能，这个故事还能基本成立吗？能=不够核心（可删可合并）；完全不行、只有分身多身份才能这么玩=高优先级保留。
**反派更早存在、晚点露脸**：阿尔登从周磊事件起就能看到物流异常/医疗数据/实验痕迹/壳公司/合规文件——读者逐渐知道"背后有东西"；正式登场=西装/合法办公室/正常业务/礼貌（比早期阴笑反派有辨识度）。
**配角欲望原则（反工具化）**：每个长期配角都有明确私人目标（升职/赚钱离开/保护下属/火星外驻名额/平安退休）——关明衡利用他们真实存在的欲望布局（提升幕后流质量）。
**阅读大纲模板（ref30 · 每章或每 2-3 章四问）**：①本段解决什么问题？②读者得到什么新东西？③关明衡的局面发生什么不可逆变化？④结尾为什么还要继续读？若某章四问全答不上来=该章有问题（训练章要变成"身体不够用"的剧情，而不是"为了变强"）。
**1-60 章六项标记（立项 · 下一阶段主任务）**：把现有 1-60 章大纲每章标记六项——剧情推进/分身玩法/人物变化/世界信息/爽点兑现/章尾问题；凡连续两三章只有"世界信息✔"（其余 ×）就合并或删除。先做 1-10 章试点。

## 主线地位线（整本书的主脊 · 分段依据，ref04）
**主角在棋盘上的地位变化才是真正的分段依据；地图变大只是结果，不是分段原因。**

```text
棋子 → 双面棋子 → 棋手 → 开棋盘的人 → 发现自己所在的棋盘也是别人造的
```

| 地位 | 形态 | 对应篇 |
|---|---|---|
| 棋子 | 夹在协调局与阿尔登国际之间，只能选边或躲 | 临江篇前期（卷一二） |
| 双面棋子 | 本体+百面+买家同时服务敌我双方，开始自己摆 | 临江篇中段（卷三四） |
| 棋手 | 商社成势，布自己的局，别家开始绕不开 | 临江篇末 → 国内篇 |
| 开棋盘的人 | 自有航线/殖民点/分基地，建立自己的棋盘 | 平行宇宙篇（实际最大地图） |
| 发现棋盘是别人造的 | 新世界同盟/企业联合玩的正是同一套，只扩大无数倍 | **世界观远景（认知揭示，不展开）** |

> **力量升级不是主线，地图升级也不是主线。** 真正不断升级的是：一开始只能骗一个人 → 能骗一个组织 → 几个组织围绕他制造的假身份互相博弈 → 最后，假的身份、假的组织、假的故事，因为全世界都相信，全部变成真的。（ref04）

> **结构权重（ref16 · 非硬性章数）**：地球约 40%（可 45）／太阳系约 15-20%／平行宇宙殖民网络约 40%。

> **方舟环=两阶段间大钩子（ref16）**：火星"方舟环"（超凡灾难最后避难所+与研究院无关的大灾变预兆）——主角先以为火星只是资源殖民地，后疑惑"为什么各国花这么大代价建能容纳大量人口的城市群"，发现超凡社会高层一直认为地球未来可能出事→平行宇宙殖民点从"资源基地"变为"避难路线"→航线权重要性暴涨→**太阳系让主角发现"为什么必须有退路"，平行宇宙让他开始建立自己的退路**（接 D-025 驱动力）。

> **世界观远景（ref15 · 不承诺进入）**：多元宇宙文明（新世界同盟/企业联合/帝国联邦）仅作为研究院身世与宇宙尺度背景存在——主角知道它存在，但永远够不到。**研究院故土=天花板，不是地图。** 理由：尺度断层（文明级实体 vs 地球 18 级天花板，前期势力全面失重）、神秘感（"去了故乡=哦，这是第 XX 型自动化研究设施"）、气质（研究院=废墟系统的残存前台，天然指向故乡不可达）。

**后期篇进入条件（条件门控 · 不以固定章数/固定星球事件推进，ref04-九）**——大于"主角变强该换地图"的答案才算成立：
- **太阳系**：商社需要只有航线权持有人才能获得的资源，地球利益集团绕不开月球的超凡国际秩序；同时方舟预案第一次进入主角视野。
- **平行宇宙**：商社战略瓶颈=所有高利润环节都被"航线"卡住（过路费/材料受制于人/危机时无自己的避难地点）→ **"我不能让自己的唯一退路掌握在别人手里"（D-025 人格逻辑的组织层面）** → 要一条自己的航线（从"使用别人的棋盘"到"建立自己的棋盘"）。
- **多元宇宙**：**不进入**。研究院故土殖民战争仅作主题镜像（大小棋盘镜像的认知揭示），不开启地图（ref15）。

**临江篇终局（ref04-七 · 卷末姿态）**：协调局认为他是可培养的好苗子；金水物业知道"百面"不能随便得罪；同业会与"神秘买家"有长期生意；散修圈听过第三个分身；阿尔登国际亚太分部丢了一个关键据点却不知道是谁做的——而所有人不知道这些线通向同一个 17 岁少年，他仍坐在教室里上自习。**这才是临江篇完成时该有的画面。**

**舞台层级（整本书地图）**：地球局（临江篇）→ 国内/地球帷幕后 → 太阳系 → **平行宇宙殖民网络（实际故事最大地图）→ 多世界网络阶段（不换地图，网络经营=最终棋盘）**；每一层都是上一层的新棋盘，地图扩张以"多身份闭环跑满"为门槛，不按固定章数。**多元宇宙=世界观远景，不作为舞台层级**（ref15）。

## 钩子管理（三层 · 唯一最亮，ref05）
**永远同时存在三种距离的钩子，且任何时候只能有一个"最亮"的主钩子**（其余压暗，尤其研究院之谜保持"很淡地存在"）：

| 层级 | 读者在追什么 | 回报周期 |
|---|---|---|
| 近钩子 | 眼前这件怪事怎么解决 | 1-3 章 |
| 中钩子 | 周磊为什么失踪？谁压案？百面能不能混进去？ | 5-15 章 |
| 远钩子 | 觉醒潮真相、研究院来历、方舟预兆 | 数卷~全书 |

**主钩子轮换（第 1-35 章参考）**：1-3 章"我的眼睛到底怎么了"（六边形是更大异常）→ 3-10 章"周磊去哪了，我会不会下一个"→ 11-16 章"协调局到底是什么世界，周磊还活着吗"→ 16-22 章"谁在做实验，为什么局里有人阻止"→ 23-35 章"百面能不能真的混到敌人身边"。**钩子必须不断"回答旧问题，同时制造更危险的新问题"**（见 f002 悬疑阶梯），杜绝"一个问题拖 30 章"。

## 爽点体系
苟住发育、复刻对手能力打脸、身份切换反杀、随身基地藏人、假死洗白、情报碾压、跨体系名场面。**多身份爽点必须逐级加码**：第一次只是"分身当路人套话"，第二次是"两个身份互喂信息"，第三次是"三个身份同时在场制造不在场证明"——一次比一次复杂。**组织由假变真（ref04-八）**：假身份 → 假关系 → 假组织 → 因越来越多人相信而变成真组织；"命名"是承认既成事实的节点，不是开张仪式（f005）。

**新分身爽点公式（ref22 · 大纲规则）**：旧容量被塞满 → 主角因少一个身体付出代价 → 突破瓶颈 → 新分身出现 → 立即兑现以前不可能的操作 → **新身体同时制造新麻烦**（升级永远同时扩大自由与负担）。
**分身爽点八类（ref22）**：①不在场证明（百面犯罪时关明衡在协调局开会）②自己证明自己（拍卖会上"百面"与"买家"当众吵架=两人不可能是同伙）③自己和自己谈判（百面买/买家卖，表面维护敌对利益，故意谈崩一次）④制造根本不存在的组织（A"问上面"→B"上面的意思"→C"确实有个上级"=三层结构，实际一人坐床上）⑤信息套利（三组织各持一段，只有他拼完整）⑥故意让一个分身输（"输也是布局"，让对方低估）⑦自己追杀自己（协调局令调查百面，负责人是关明衡：认真调查/提供可信线索/让"百面"逃掉/甚至当众打一场）⑧自己杀死自己（百面假死：尸体/现场/目击者/追杀过程由多个"他"共同完成）。
**后期升级（ref22）**：从"同时多开"升级为"**身份之间存在真实关系**"——百面有朋友/买家有客户/修士有师父；"如果百面的朋友讨厌关明衡""如果分身师父与协调局敌对""如果两个身份答应了冲突的事"→更多分身=更多责任（与主角私人伦理结合，见道德边界）。平行宇宙阶段=分身玩法第二次爆发：**一个分身第一次不回来了**（常驻异世界，本体高中毕业时某个"他"已在另一世界生活两年）。

## 关底设计（两级 · Boss=玩法漏洞压力测试器，ref07）
- **核心标准**：每个关底 Boss 必须"发现主角当前玩法的漏洞"，逼主角进化出下一种玩法。打完 Boss 不是单纯升一级，而是学会一种新的幕后玩法（例：旧厂区 Boss 发现"分身留痕可被追"→主角学会控制痕迹；风控负责人发现"百面背后必有组织"→主角把不存在的组织变成真的）。
- **两级关底**：卷二小关底=旧厂区项目主管（专业人员，第一堂"分身不是无限探路炮灰"的课）；临江篇大关底=阿尔登国际亚太分部风控负责人（棋手，"给人和风险定价的人"，逼出三个身份首次协同）。
- **强敌升级轴**：怪物（未知）→ 专业人员 → 棋手 → 组织 → 制度；不用"3级→5级→8级→12级"式数值升级。
- **危机尺度防膨胀**：临江前期危机上限=几十人会死 + 主角身份网可能全暴露 + 协调局会抓错人 + 阿尔登国际准备全身而退；严禁第一阶段就上"城市毁灭级"。
- **临江篇整体结构（ref09）**：第一场危机让关明衡发现"合法世界下面藏着犯罪"→ 第一次胜利让官方打掉阿尔登的一根手指、抓不到整只手（**犯罪成立、集团责任未成立**）→ 随后主角用百面主动钻进那只手里面（**危机制造了招募需求**）→ 大关底=阿尔登切断整条临江黑线，主角反过来利用这次清场让百面"死亡"、让自己的虚构组织真正诞生。
- **三角关系（ref09 · 前期终态）**：官方认为关明衡是自己人；阿尔登认为关明衡是可正常接触的官方年轻人（甚至合法给他发工资）；官方在调查阿尔登；阿尔登在调查一个不存在的幕后组织；**关明衡同时站在这三条线上**——"谁认为谁是谁"的发动机建立。
- **关底形态偏好**：限时事件（如撤离协议 72h）优于"Boss 追着打"；终局"棋局上赢、战斗上勉强活"优于主角亲手击杀；Boss 输但不必死，输得彻底即可。
- **三线关底**：第一大篇高潮=本体（协调局内推动且不暴露）/ 百面（接受审查/最后任务）/ 买家（转移资源、制造"第三方存在"假象）三线同时行动——五股势力同时动，其中三股都是关明衡。

## 写作原则
- 主角始终保留底牌，分身数量与真实能力永远比外人以为的多一层。
- **驱动力锚点（ref05）**：一切行为动机回到底层欲望——活下去别连累家人 → 不能只依赖外人（含官方）→ 始终留第二条路。主角不是"看见不公就管"的少年英雄，别因情节方便让他逞义气。
- **道德边界（ref18/19/20/21 · 私人伦理强、公共道德中等偏弱，中心 5.5，重大情境可摆 4.5/6.5）**：默认不无意义伤害陌生人，但对陌生人不承担无限责任；**非工具化红线**（无辜者可处于风险中但不能被主动设计成工具，公交炸弹=绝对不做）；**关系距离**（自己人/朋友/陌生人/灰色相关者/敌人道德值逐级下降）；**三条保护栏**：不以伤害人为乐／不轻易背叛把命交给自己的人／**不习惯性地把人命简化成账面数字**（与阿尔登的最终分野）；**多米诺骨牌原则**："我不负责救所有人，但我得为自己主动推倒的第一块多米诺骨牌负责。"行为边界随故事阶段变化但不黑化（开局 6-6.3→临江 5.5-6→百面阶段 5-5.5→商社成型 5.3-5.7 重建私人伦理）。写作时严禁"这章冷酷、下章圣母"的漂移。
- **人物一致性写作规则（ref21 · 头号人物规则）**：**不要问"这一章该让关明衡善还是狠"，而要问"这一章他认为自己对谁负有责任，又愿意让谁承担什么代价"**——答案连续，人物就连续。配套工具：①七步判断顺序（关明衡卡：责任→关系→敌我→可逆→替代→后果→认不认）②**方案排序随阶段变大**（开局：报警/躲开/骗/制服 → 临江中期：骗/借官方/利用身份/制服/杀明确恶性 → 百面：操纵信息/借刀/破坏资源/让敌人暴露/击杀看收益 → 商社：先问"有没有必要让这个人成为敌人"，收买/合作/分化/放过/杀掉都只是手段——弧光=工具箱变大，不是不敢杀→杀人不眨眼）③**不总找完美第三方案**（分身多开不能每次都成功：数量不够/信息错误/第四危机/身份不能暴露/隔世界/差 30 秒——必须偶尔逼他真选）④**道德镜子**（协调局=程序责任、阿尔登=极端工具主义"任何生命都只是成本问题"、主脑=结果计算（"方案二减少总伤亡31%""但方案二需要主动杀一个没参与的人""正确""那不用"）、父亲=朴素伦理"做人别欠人家的"——通过对白呈现，禁止主角哲学独白）⑤允许判断错（见关明衡卡"判断错教训原则"）。
- **副本公式（ref05）**：一个当前需求 + 一个现有身份解决不了的障碍 + 一次新的分身用法 + 一个永久性剧情收益 + 一个由胜利制造出来的新麻烦。副本结束后必须埋"下一条剧情的引信"，禁止"出任务→打怪→拿战利品"三件套。
- **副本难度 = 冲突四轴（ref05）**：信息冲突 / 身份冲突 / 时间冲突 / 利益冲突逐级加码（我不知道发生了什么→知道但没权限→有权限但身份不能出手→要同地两场→两任务互相冲突→百面的正确选择伤害本体利益→本体为保百面在官方内部故意做"错误判断"）。**战斗等级只是底噪**。
- **70/30 势力观（ref05）**：前期副本约 7 成扩世界、积累人物，3 成暗推进主线——**阿尔登国际不是"临江万恶之源"**，它只是这个完整社会里的一个坏玩家。每卷至少留 1-2 个纯扩世界副本、举 1 个与阿尔登国际无关的对手（山门/散修/资本/民间杂术）。
- **家庭线/校园线非副本（ref05）**：关志远不该频繁被绑架、林小满不该反复被超凡波及；他们的功能是"让主角回到正常生活"（前一晚百面被追杀，第二天早上父亲问"数学卷子签字没有"的反差，正是本书味道）。这类桥段用于**验证主角为什么需要力量**，不作推进阴谋的钥匙。
- **功能分工（ref14）**：研究院=谜（读者追"它究竟是什么"）；主脑=关系（读者追"它和关明衡最后会变成什么"）；分身=玩法（读者追"这次关明衡准备怎么玩"）——三者互不代替。研究院的一切功能源于"解析/实验/重构"三动词，须通过"物种进化研究设施是否合理拥有"的检验；它靠**需求制造剧情**（识别异常/判定资源/逼主角选择/质变须主角完成/暴露规模），不靠直接解决剧情。
- 研究院残存数据按节奏释放（详见 world.md 展现节奏），且遵循**现实镜像原则（ref04-十）**——释放永远慢主线半拍：主角先在现实中经历某种结构（建供货网络→残存数据"供应链/自动工厂"；接触异世界航线→"拓殖舰队"；参与殖民点争夺→才得知故乡的殖民战争），研究院残存数据 = 现实剧情的巨大镜像。
- 各势力永远在博弈，主角永远在"夹缝中多开"。
- **构纲六问（ref04-终节）**：设计每个大篇先回答——①篇始关明衡是谁？②他想得到什么？③为什么现有身份拿不到？④因此必须制造什么新身份/新关系/新组织？⑤解决问题后无意间制造了什么更大的局？⑥篇末别人眼中的世界 vs 真实世界的信息差有多大？六问都有强答案，大纲才成立。
- **玩法升级模型（ref04-五）**：每个大弧按"遇到当前身份解决不了的问题 → 被迫开发新身份/新玩法 → 解决旧问题 → 制造更大的新麻烦"推进；下一阶段永远是上一阶段解决问题产生的副作用（主角自己的选择把自己推进下一层）。禁止"新地点→新任务→打架→得资源"的换皮模板。
- **五轴验收清单（ref04-二）**：每个阶段除"进入条件/核心冲突/退出状态"外，用五轴自检——身份网 / 主角实力 / 主角势力 / 主要敌手 / 世界真相；**每换一次地图，至少两条轴同时质变**（例：进火星不是"三个身份换个城市跑"，而是三个身份第一次真正生活于三个彼此隔绝的社会环境）。**注意：五轴是验收清单不是解锁表**——实力推进由剧情需求驱动（见玩法升级模型），不允许"换地图=解锁新能力"。
- **周磊案悬疑阶梯（ref04-六）**：同一条主线按"换问题"分层回收——发生什么（卷二）→ 谁做实验（旧厂区）→ 为何被允许（局内利益网/f004）→ 实验想实现什么（分部）→ 阿尔登国际为何需要这技术（本部主线）。每隔一段给一个真答案，答案后面永远有更大的问题，避免"同学案查五十章"。
- **地图扩张的内生动力（ref17）**：关明衡离开临江/地球不是因为"篇写完了"，而是因为**当他的真实力量、分身规模和商社体量达到一定程度后，地球本土越来越容不下他完整展开**（高阶力量地表限制制度：《天幕协议·高阶力量附则》，见 power_system.md）——故事舞台自然向外扩展。
- **大世界钩子（ref17）**：前期翻档案发现"临江最高等级档案只有 10 级左右"→"再往上的，大多数不在地球。""以后你够级别再说。"——读者第一次意识到"真正强的人去了哪里"（月球/火星/平行世界），不需前期讲太阳系殖民史。
- **分身限制兑现清单（ref31 · 规则必须真的伤到主角）**：前 65 章至少让读者真正经历——①主锚差点出事一次；②认知带宽过载导致一个身份差点穿帮一次（卷四特别适合：百面面对阿尔登/本体受协调局盘问/买家完成交易，三身份同时撒谎→语言错位/把 A 身份信息说给 B 身份的人）；③回收式记忆导致两个身份根据不同信息做出冲突选择一次；④同源残留真的让专业人士沿线追过一次。这些限制只存在 Bible=等于不存在。
- **停止继续增加分身限制规则（ref31）**：限制设计已足够，下一步是兑现规则，不是加规则。
- **前 65 章节奏（ref03-4）**：临江篇内**放慢"功能全部解锁"**——外貌塑造大面解锁、独立基因（阶段 5）、商社成型均安排在临江篇后段甚至更后；**"身份不完美期"是最有味道的时期**（不能掉发、不能留血、监控习惯雷同、两身份不能同框等约束正是剧情）。每次升级遵循"消灭一种风险、引入一种更高级风险"（见 clone_rules.md），严禁一次升级让身份伪装全面无伤。
- **大小棋盘镜像（ref01-二 + ref15）**：地球帷幕后的"太空殖民/平行宇宙拓殖/航线垄断"，其实是研究院故土多元宇宙霸权（新世界同盟 vs 企业联合）在低维度上的同构翻版；后期破题点出"主角看到的殖民游戏，只是小学生在模仿宇宙级霸权正在做的事"——**这是主题揭示，不是地图承诺**：主角知道更大棋盘存在、但永远够不到（研究院故土=天花板）。太空与平行宇宙设定保留但不提前揭露，严格延迟。
- **母题：表面之下还有一层（ref06）**：全书反复出现"看穿表面"——骨架在皮肤下 / 钢筋在墙面下 / 超凡社会在普通社会之下 / 百面之下还是关明衡 / 地球帷幕后之外还有殖民世界。开篇即用三次误判微缩此母题（"我觉醒了透视"→错；"研究院给了我能力"→错；"周磊转学了"→错），表层解释总是不够。开局与后期揭谜都要保持这一回响。
- **大后期能力终点主题（ref23）**：分身主体演化线=固定主锚 → 主锚可迁移（平行宇宙阶段）→ 分布式主体（大后期）——**当几具身体、几个身份、几段人生全都是真实的自己时，"本体"这个词本身还有没有意义？** 这比"分身数量从 3 升到 30"更值得作为大后期能力终点（时间点克制：临江=固定本体；地球/太阳系中期=仍固定+主脑怀疑主锚可变；平行宇宙=首次迁移；大后期=分布式）。
