# 设定变更记录（Decisions / Retcons）

> 本文件只记录**已拍板的设定变更**：旧规则是什么、为什么改、改成什么、影响哪些文件。变更必须先在 bible/ 或 rule 文件落地，再动正文；state 永远反映已定稿正文。
>
> 冲突优先级见 AGENTS.md：定稿正文 > Bible 硬规则 > State > 角色卡 > 分卷/弧/单章大纲 > 备选方案。

## D-001 分身评级规则：数量 ≠ 等级（2026-08-17）
- **旧规则**：成长线按"1 级=1 个分身、2 级=2 个分身、3 级=3+ 个分身"推进，与"特殊系按单体强度评级、分身总数另行备案"冲突。
- **新规则**：**等级 = 能力本体的质变；分身数量是升级的结果之一，不是评级原因。** 官方单体评级与成长线不再互掐（ref01-五）。
- **影响**：`bible/power_system.md`（主角等级映射、四、主角能力表）；`bible/clone_rules.md`（新增，硬规则）。

## D-002 记忆同步机制：回收式（2026-08-17）
- **旧规则**：早期写"意识同步"，后期又写"通过研究院回收记忆同步"，两者打架。
- **新规则**：**回收式同步（默认）**——分身不共享实时记忆，回收那一刻才合流；本体一次只实时沉浸一份视角，其余分身进入托管。分身死亡 = 未回收记忆永久丢失 + 本体精神重创。这是"自己查自己、身份互相不知情"谍战玩法的地基（ref01-六）。
- **影响**：`bible/clone_rules.md`；`characters/main/关明衡.md`；后续章节正文。

## D-003 契约国际主题收束：能力资产化（2026-08-17）
- **旧定位**：普通"跨国邪恶公司秘密做活体实验"。
- **新定位**：**把"能力"从人身上剥离，变成可交易、可授权、可复制的资产（能力移植/复制/拼接）**，与主角"复现型分身"形成黑暗镜像（人的商品化 vs 人的扩展）。（ref01-八）
- **影响**：`bible/factions.md`；`characters/orgs/契约国际亚太分部.md`；`characters/support/周磊.md`（混合异能残留=移植拼接产物）。

## D-004 第一卷开头版本冻结（2026-08-17）
- **冲突**：单章细纲 vs 卷纲/弧纲对"第 1 章进不进研究院"不一致（单章纲把透视×2+六边形+入院全塞进第 1 章）。
- **冻结方案**：**第 1 章 = 两次透视 + 章末六边形钩子止步（不进研究院）；第 2 章开篇进入研究院、主脑苏醒。** 原因：第 1 章要完成"异常出现→否认→再验证→确认异常"的小闭环，入院会提前消费钩子（ref01-十）。
- **影响**：`outline/chapters/001.md`、`outline/arc_001.md`、`outline/volume_01.md`。

## D-005 周磊失踪动机：自保 > 义举（2026-08-17）
- **旧设定**：谨慎型主角因"普通同学失踪"冒险查案，动机缺口。
- **新设定**：周磊失踪前也有"头痛/体检异常"史，接走他的黑色商务车又出现在校门口 → 主角怀疑"觉醒者正在被抓"，自己刚觉醒可能就是下一个 → "我不是在当侦探，我在确认下一辆车是不是来接我的"（ref01-四）。
- **影响**：`outline/volume_01.md`、`characters/support/周磊.md`、`outline/master_outline.md`。

## D-006 特训生情报入口：低权限数据岗（2026-08-17）
- **旧设定**：17 岁特训生"浏览办事处档案"发现串案，权限违和。
- **新设定**：特训生被安排旧案电子化、登记材料录入、失踪案数据清洗等杂活，串案在数据清洗中发现——**别人靠级别拿情报，他靠不起眼的位置拿情报**（ref01-七）。
- **影响**：`outline/volume_01.md`（ch9）、`characters/orgs/协调局.md`（低权限岗制度）、`outline/volume_03.md`（ch35 档案复核的合理性）。

## D-007 研究院扫描方向性（2026-08-17）
- **旧设定**：第一卷末"扫描视界例行扫视城市"易被理解为城市级战略侦察。
- **新设定**：扫描受力于主角视线方向与周边（片段式，一次几十秒、约 20 分钟一次），**非城市级**（ref01-十一）。
- **影响**：`bible/clone_rules.md`；`characters/main/关明衡.md`；`outline/volume_01.md`（ch10 只写"朝向周磊家方向"）。

## D-008 林小满定位定版：少年人朦胧好感（2026-08-17）
- **旧漂移**：人物卡"情感线可选未定" vs 单章纲"好感对象"。
- **定版**：对同桌的少年人朦胧好感，未挑明、不外显；可淡化为友谊线，也可升温为情感线，两者通路（ref01-十一）。
- **影响**：`characters/support/林小满.md`、`outline/chapters/001.md`（用词统一）。

## D-009 关志远唠叨修正（2026-08-17）
- 17 岁儿子无"催婚"，改为催成绩、催志愿、催早点睡、催"以后找个稳定工作"（ref01-十一）。
- **影响**：`characters/support/关志远.md`。

## D-010 身份欺骗原型：15 章前预演（2026-08-17）

# 第三批（2026-08-18，依据 ref04，经评价后采纳）

## D-017 主线压测句 + 地位升级线
- **新增**贯穿全书的一句话：关明衡从一个试图隐藏自己的觉醒者，逐渐变成**制造身份、制造组织、制造局势**的人。

- **影响**：`outline/master_outline.md`（一句话/主线地位线表）。

## D-018 构纲六问 + 五轴验收清单（非解锁表）
- 每大篇先答六问（篇始是谁/想要什么/为何身份拿不到/必须制造什么/无意间制造什么更大的局/篇末信息差）；每阶段用五轴（身份网/实力/势力/敌手/世界真相）验收，**换地图至少两条轴质变**。
- **重要修正**：五轴是验收清单不是解锁表——实力推进由剧情需求驱动，禁止"换地图=解锁新能力"（防与 ref03 风险代际冲突）。
- **影响**：`outline/master_outline.md`（写作原则）。

## D-019 商社由传闻变成事实（f005 演化线）
- 商社不"成立"而"长出来"：第一笔交易→固定合作人→供货商传闻→有人主动找"他们"→为维持假组织制造联系人/仓库/情报→"有十几个人靠它吃饭"→才正式命名；**命名=承认既成事实的节点**。
- **影响**：`outline/master_outline.md`（爽点体系）、`state/foreshadowing.md`（f005 写法）、`state/foreshadowing.json`（f005 planned_payoff）、`outline/volume_03.md`（多身份闭环注记）。

## D-020 周磊案悬疑阶梯（五层答案）

- **影响**：`state/foreshadowing.md`（f002 写法）、`outline/master_outline.md`（写作原则）。

## D-021 研究院碎片"现实镜像"原则
- 碎片永远慢主线半拍：先有现实结构（建网/走航线/立据点），再出现镜像词汇（供应链/自动工厂、拓殖舰队、殖民战争）；禁止随机掉设定。

## D-064 分身同步机制三层化定义 + 主动上传成长点
- **旧（ref23 决案）**：同步两维合并——感知层实时+记忆层回收式+注意力层认知带宽（clone_rules 二）。
- **新**：明确为**三层制**——
  - ①**存在状态层（实时）**：关明衡始终知道某身体活着/移动/遇险；分身被杀半小时本体无感=过分割裂，禁止。
  - ②**当前感官层（实时可访问，需切换注意力）**：A 正看的电话号码，本体切过去就能看见；但一次只有一个前台注意力，本体与领导高质量撒谎时无法同时逐字读 A 面前的合同（带宽限制，不是延迟）。

  - **总纲一句**：一个意识，多个身体——感知可实时切换，注意力共享带宽，详细经历回收后完整合流。
- **新成长点**：后期（跨地球/火星/平行宇宙）解锁**主动上传明确信息**（"目标已到""位置A17""不要行动"=同一个人给自己发即时消息）；边界=只传明确信息，禁止全量思维同步（否则退回全共享）。
- **写作纪律**：感知实时 ≠ 信息全同步；"本体真的不知道分身最新详情"是真实信息差，不是作者装傻；**分身专属失误**（身份戏直接产生危险，如百面说"我没见过关明衡"时本体被叫名字差点答应）保留为招牌玩法（优于数值惩罚）。

## D-065 回收/对齐双轨制：同步机制三时代（回收→对齐→分布式）
- **旧（D-002 + D-064）**：回收=主动召回/解散分身+完整记忆合流，是完整经历同步的唯一方式（前中期谍战地基）。

# 第四十三批（2026-08-18，作者决定）

## D-070 强制执行层：git pre-commit hook 接入一致性审计
- **背景**：D-067/068/069 均为文档化约定+手动校验（AGENTS.md 靠模型自觉、audit.py 靠手动运行），无不可绕过的强制闸门——机制可能被跳过。
- **新机制**：
  - `scripts/hooks/pre-commit`（源文件入库可分享）+ `scripts/install-hooks.sh`（安装到 .git/hooks/）：**每次 git commit 前自动运行 `scripts/audit.py`，存在 ERROR 则阻断提交**（提示修复或 `--no-verify` 强制）。
  - `scripts/audit.py` 新增 hook 安装状态检测：hook 未安装或与源文件不一致时输出 INFO 提示（防强制层静默丢失）。
  - 实测验证：故意破坏 JSON → 提交被阻断（git log 无新提交）；恢复后 audit 0 错误。
- **强制层结构**：AGENTS（软约定）→ audit.py（可执行校验）→ pre-commit hook（不可绕过的闸门，除 --no-verify）。
- **影响**：`scripts/hooks/pre-commit`（新增）、`scripts/install-hooks.sh`（新增）、`scripts/audit.py`（hook 状态检测）、`AGENTS.md`（强制层说明）、`meta/changelog.md`。

## D-071 修订留档与同步机制强制化
- **背景**：D-069（revision log）与 D-068（会话同步）仍为软约束——AI 可能跳过建 log、跳过读取前检查。需要强制闸门。
- **新机制（pre-commit 扩展，D-070 同钩子）**：
  - **修订留档强制**：本次提交若修改了 `Novel/chapters/NNN.md` 或 `Novel/outline/chapters/NNN.md`，且 `revision_index.jsonl` 未随本次提交更新 → **阻断提交**；提交信息含 `[no-revlog]` 可显式豁免（纯格式/typo 等无需留档的修改）。

# 第四十六批（2026-08-19，作者决定）

## D-073 人工改稿与版本比较纳入 Revision log
- **背景**：人工润色可能同时改变文风、场景范围、人物任务、时间地点转场与 canon；若只给口头评审、不登记修订索引，后续无法追踪哪些表达应采纳、哪些设定应回退。
- **规则**：用户/作者人工修改正文或细纲，与 AI 修改采用同一套 Revision log；版本比较只要形成可执行的采纳、回退或待验证结论，也视为一次实质修改并建立独立 revision。
- **待审状态**：人工版本尚未通过一致性审计时，stage 必须标记 `review_pending`；此时只记录比较基线、风格变化、canon 风险和候选处理，不进行 canon bump，也不让待审正文覆盖 outline/state。
- **边界**：revision 不保存整篇 Before/After；全文仍由 Git 或明确的版本基线承担。纯阅读且没有形成任何正文判断，不强制留档。
- **影响**：`AGENTS.md`、`meta/revisions/r000019.md`、`meta/revision_index.jsonl`、`meta/changelog.md`。
