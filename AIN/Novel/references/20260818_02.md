# ref04（2026-08-18）：第三评审——"大纲的骨架单位要改对"

> 核心诊断：粗纲目前更像"世界展开路线图"，不是能支撑长篇连载的"剧情路线图"。核心主张：**整体粗纲按"主角在棋盘上的地位变化"划阶段；前期细纲按"身份玩法升级"划剧情弧；地图变大只是结果，不是分段依据。** 已按我方评价选择性采纳，落点见 decisions D-017~D-024。

## 二、整本书真正的主线句
关明衡从一个试图隐藏自己的觉醒者，逐渐变成**制造身份、制造组织、制造局势**的人。升级轴不是"弱→强→更强→宇宙级强者"，而是：
**棋子 → 双面棋子 → 棋手 → 开棋盘的人 → 发现自己所在的棋盘也是别人造的。**
研究院、多元宇宙、殖民战争由此统一（后期霸权玩的正是主角一路学会的那套，只是放大无数倍）。

## 三、五条成长轴（作验收清单，不作解锁表——我方修正后采纳）
每阶段检查：身份网 / 主角实力 / 主角势力 / 主要敌手 / 世界真相。
**每换一次地图，至少另有两条轴同时质变**（进火星=三个身份第一次真正生活在三个不同社会环境，玩法才升级）。避免"临江副本打完去火星打怪"。

## 四、第一大篇章：临江局（1-65）
统一看成一件事："关明衡第一次学会同时站在棋盘的几个位置"，一条完整的能力使用史，六个阶段：
1. **觉醒期**（"我怎么了"）：终点=第一次主动用分身解决现实问题（ch6 双开、ch7 保护父亲极重要）
2. **入局期**（"这个世界怎么运行"）：登记/等级/异常物/同业会/任务生态；**认知转折=官方很好用，但官方不是答案**（ch22"一个身份不够用"应是前期结构轴心）
3. **多开期**（"一个身份不够怎么办"）：百面+买家；**必须尽快出现一次完整多身份闭环**；前 22 章=为什么需要多身份，卷三起=怎么用多身份
4. **双面期**（"能否同时服务敌我双方"）：契约卧底、自己查自己
5. **成势期**（"假身份能否变成真势力"）：第三身份、人才与贸易
6. **临江终局**（"谁才真正看清整张局"）：主角成为临江隐形棋手

## 五、玩法升级模型（每个大弧）
"遇到当前身份解决不了的问题 → 被迫开发新身份/新玩法 → 解决旧问题 → 同时制造更大的新麻烦"；下一阶段永远是上一阶段解决问题产生的副作用（主角自己的选择把自己推进下一层），而非"新地点→新任务→打架→得资源"。

## 六、周磊案=第一根藤，分层回收（悬疑阶梯）
五层答案：①周磊发生了什么（卷二）→ ②谁做的实验（旧厂区）→ ③为何被允许（局内利益网）→ ④实验想实现什么（分部）→ ⑤契约国际为何需要这技术（本部主线）。每隔一段给一个真答案，答案后面还有更大的问题。

## 七、临江终局画面
不是统治临江，而是成为**所有人绕不开、却不知这些线通向同一个 17 岁少年的人**：协调局视其为好苗子；金水物业知"百面"不能得罪；同业会与"神秘买家"有长期生意；散修圈听过第三个身份；契约国际分部丢据点却不知谁干的。他仍坐在教室上自习。

## 八、商社不要"成立"，要"长出来"
幕后流组织成长不是"找办公室宣布成立"，而是：第一笔交易 → 第二个固定合作人 → 供货商传闻 → 有人主动找"他们" → 被迫造联系人/仓库/情报/人手 → 主角意识到"真有十几个人靠它吃饭"→ 才正式命名。**"命名"是承认既成事实的节点**。粗纲把"商社成立"改为"商社从传闻变成事实"。

## 九、后期篇条件门控
太阳系、平行宇宙、多元霸权只需定：进入条件 / 核心冲突 / 退出状态。例：进太阳系=商社需要只有航线权持有人才能获得的资源、方舟预案入视野；进平行宇宙=商社想摆脱其他势力航线控制→必须自有殖民点/航线（从用别人的棋盘到建自己的棋盘）。

## 十、研究院身世线慢主线"半拍"（镜像原则）
主角先在现实剧情经历某种东西，碎片才告诉他"更大的世界里也有类似东西"（建供货网→"供应链/自动工厂"；接触异世界航线→"拓殖舰队"；参与殖民点争夺→才知故乡殖民战争）。碎片=现实剧情的巨大镜像，非随机掉设定。

## 十一、前期总结构（六阶段表）与六问构纲法
每大篇先答六问：①篇始关明衡是谁？②他想得到什么？③为什么现有身份拿不到？④必须制造什么新身份/新关系/新组织？⑤解决问题后无意间制造了什么更大的局？⑥篇末别人眼中的世界与真实世界的信息差有多大？

## 总结
力量升级不是主线，地图升级也不是主线；真正该升级的是"骗术规模"：骗一个人 → 骗一个组织 → 几个组织围绕假身份互相博弈 → 假身份/假组织/假故事因全世界相信而变成真的。这条线贯穿始终，比"分身+研究院+宇宙升级"更有辨识度。
