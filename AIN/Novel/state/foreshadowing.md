# 伏笔写法指南（foreshadowing.md）

> **职责**：只记录每条伏笔"怎么写、什么能透露、什么不能透露、设计意图"。结构性字段（id / type / status / planned_plant / actual_plant / planned_payoff / actual_payoff / related_* / reveal）一律以 `foreshadowing.json` 为准，**本文不重复核心事实**，只给写法与尺度。
>
> **type（见 json type_taxonomy）**：mystery 长期谜题 / clue 案件线索 / setup 未来剧情铺垫 / reveal_gate 信息释放限制 / promise 明确承诺。不同性质不塞同一个桶。
>
> **reveal 字段（信息解锁表）**：研究院、方舟预兆、主角真实能力这类顶级秘密，`hero_knowledge_level`（关明衡当前允许知道到哪级）与 `reader_reveal_level`(读者当前允许读到哪级) 只在正文写到对应阶段时上调，**防止 AI 正文"顺嘴剧透"**。
>
> 状态流转：chapter 定稿后，对应伏笔在 json 中从 `planned` 改为 `planted`/`developing`，本文无需改动。

## f001 研究院绑定之谜
- **设计意图**：金手指的第一层悬念，"钥匙与锁"解释给出表层答案，保住深层疑问。
- **可透露**：第 2 章"同频"解释（复现型能力与"解析万物"协议同频）即止。
- **不可透露**：基因变异为何是这个方向、研究院真实来历（禁止提前剧透多元宇宙背景）。
- **写法**：第 1 章只呈现"六边形是什么"，不做任何解释性旁白；第 2 章借主脑之口解释到"被钥匙唤醒"为止。
- **回收（ref15 · 四层答案，不进入故土）**：大后期=恢复研究院历史记录确认身世及损毁原因；**那是研究院的过去，不是关明衡的未来**——新世界同盟是否仍存在保持未知，故土=天花板而非地图。

## f002 周磊失踪案 → 阿尔登国际实验网络
- **设计意图**：第一卷主线抓手，兼主角自保动机的锚（失踪的是觉醒者=下一个可能是我）。
- **可透露**：第 1 章"周磊空座"一闪（不调查）→ 第 3 章"转学"宣布（书/书包都还在）→ 黑色商务车 → 串案；第 10 章卷尾"周磊家方向异常能量痕迹"。
- **不可透露**：失踪者与阿尔登国际直接对应关系（第二卷才挑明）；实验是"能力移植/拼接"。
- **写法**：案件先于组织登场——读者先看见"现象"，再在第二卷看见"幕后"；失踪者混合异能残留的描述务必克制（先给"异常"，后给"属于多个已故觉醒者"）。
- **悬疑阶梯（ref04-六）**：同一条线"换问题"分层回收，每隔一段给一个真答案、答案后面永远有更大的问题（避免"同学案查五十章"）：①周磊发生了什么（卷二 ch16 现身/失忆）→ ②谁做的实验（旧厂区·样本筛选站）→ ③为何被允许（协调局利益网 / f004）→ ④实验想实现什么（**通用受体计划**：寻找能反复承载外来异能的身体，把异能从"必须雇佣一个人"变成"可移植的资产"——周磊是失败样本之一；旧厂区只是筛选+初步兼容性试验站）→ ⑤阿尔登国际为何需要这技术（本部主线，能力资产化的最终形态）。

## f003 主脑残存数据
- **设计意图**：研究院线/多元宇宙线的渐进释放通道，与修复进度绑定。
- **可透露**：按 bible/world.md 展现节奏——卷 1-3 只有破碎词汇；卷 4-5 出现"自动工厂""拓殖舰队"。
- **不可透露**：殖民战争、霸权名（新世界同盟/企业联合）提前出现。
- **写法（ref13）**：碎片只在修复节点释放，一次一到两个词级信息，用主脑"语焉不详"过滤；**呈现方式=残存系统输出，不是记忆闪回**（"`连接失败：第 17 自动工厂集群 / 状态：不可达`""`拓殖舰队权限认证模块：损毁`"——关明衡问"那是什么"，主脑答"相关定义缺失"）。主脑话术守"残缺规则"（不说"我想不起来"，说"存在历史索引，源数据缺失"）。
- **镜像原则（ref04-十）**：碎片永远慢主线半拍，是现实剧情的巨大镜像——主角先建供货网络、碎片才出现"供应链/自动工厂"；先接触异世界航线、才出现"拓殖舰队"；先参与殖民点争夺、才得知故乡的殖民战争。禁止随机掉设定。
- **大后期恢复（ref13 + ref15）**：不是"想起来了"，而是数据修复流程（修复存储阵列→恢复密钥→找回索引→重建日志→解锁物理隔离数据舱→读到霸权名）；**研究院内部身世回收篇**——旧权限系统/物理隔离数据区/损坏历史日志/未启动设施逐步访问拼出全史；甚至可发现损毁并非一次爆炸（战争损坏 vs 自动销毁 vs 炸飞前主动隔离=小型悬疑弧）。连接旧网络=无响应、重建返回路径=不可行。可选尾声：收到一段极微弱的握手信号（协议版本无法匹配/来源无法定位/认证格式属新世界同盟体系）——"是否回复？"（留门，不承诺续作）。

## f004 协调局内鬼压案
- **设计意图**：官方线中期转折，"内部问题"比外部敌人更近更紧。
- **可透露**：第二卷压案时上级态度的暧昧、档案转移记录被动的痕迹。
- **不可透露**：内鬼身份（第四卷揭）；其与阿尔登的利益关系。
- **写法**：只给"暧昧"与疑点，主角起疑但无证据；压案是"拖"字诀而非"不查"。
- **内鬼定性（ref08）**：不是"收钱让阿尔登随便杀人"，而是**替阿尔登降低监管强度**（延迟检查、把材料从 A 级改 B 级、对登记瑕疵睁眼闭眼、把案件按普通人口失踪处理）。他未必知道旧厂区已做到活体能力移植，可能自认在帮"违规但没破红线的商业研究"；回报非现金（国际项目名额/家属治疗/特殊药物/航线资格/子女入学/装备采购优惠）。**压案分两半：一半是真实的制度成本（阿尔登是合规供应商），一半才是内鬼**——后者后期发现真相后可能想脱身（灰色人物，非纯反派）。

## f005 百面与神秘供货商
- **设计意图**：分身 A / B 同源关联的江湖化遮掩，为商社提前种背景。
- **可透露**：黑市传闻、有心人的注意。
- **不可透露**：矛头指向主角真实身份（查不到实锤即安全）。
- **写法**：传闻要"查不到证据"且"能同时解释两种说法"；独立基因解锁前全靠谨慎与信息差兜底。
- **商社由传闻变成事实（ref04-八）**：这是前期最重要的演进线——假身份 → 假关系 → 假组织 → 因越来越多人相信而变成真组织。写作时按"第一笔交易 → 第二个固定合作人 → 有人主动找'他们' → 为维持假组织被追造联系人/仓库/情报 → 主角突然意识到有十几个人靠它吃饭 → 才正式命名"展开；**"命名"是承认既成事实的节点，不是开张仪式**（f006 假死后的商社承接此线）。

## f006 分身 A 入阿尔登国际
- **设计意图**："自己查自己"的正式开张，双面棋子的踏板。
- **可透露**：百面被招揽的过程与投名状交付的紧张感。
- **不可透露**：假意入伙的真实目的（实验网络数据）过早暴露给读者以外的人物。
- **写法**：投名状必须真金白银（有代价、有把柄），入伙可信度才成立；随后转入第四卷双面棋子的"自己查自己"。
- **招牌副本形态（ref05）**：投名状 = 一件"必须做坏事才能获得信任"的脏活——阿尔登让百面把偷走样本的"叛徒"连人带货带回来，而非简单的"押车打赢"。本体+买家+百面三身份解一道题（本体供信息、买家制造假交易、百面交人但关键证据被第三方取走），让**阿尔登（百面可靠）/ 协调局（未知势力介入）/ 黑市（百面背后老板出手）三方各得结论，而三方其实都是关明衡**。同时允许"本体为保百面，在协调局内部故意做一个模糊的决定"（第四卷延续）。
- **回收形态（ref09 + ref31）**：第四卷大关底=阿尔登"特殊资产部"华东负责人启动**资产撤离协议**（72 小时，把临江黑色业务全部撤走、制造责任人、把非法活动包装成"旧厂区项目组个人犯罪"），并选**百面当替罪羊**（构造"百面所属组织负责地下执行网络"的故事）。主角反过来利用撤离计划——**死人不用证明清白**——顺势安排百面"死亡"（f006 回收）：协调局/阿尔登/黑市三方各得合理故事，真正的人脉与渠道被"百面背后的组织"继承：**组织"事实上的胚胎"诞生（ref31 · 尚无正式名称）**——关明衡第一次发现"这个不存在的组织已经不能不存在了"；**正式命名"折光"留到第五卷**（组织拥有稳定人手/仓库/资金/信用后，命名=承认既成事实）。百面死后不廉价复活：成为"已死但江湖中越来越传奇的人"（有人冒名/声称见过百面，比"百面又回来了"值钱）。
